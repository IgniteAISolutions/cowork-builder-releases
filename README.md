# Cowork Builder releases

The public release feed for Cowork Builder, from IgniteAI Solutions. Each licensed copy of the plugin reads `latest.json` once a month and tells its owner when a newer release is waiting.

This repository holds version numbers, dates and short release notes only. The plugin itself is licensed per business and is not published here.
